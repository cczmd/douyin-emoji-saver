# Greasy Fork 列表文案 / Listing copy

## 简体中文

抖音表情包提取助手 5.1.0 可以预览和保存抖音网页评论、私信中已显示的表情。支持动态／静态筛选、去重、单独或多选保存。动态 WebP 和 APNG 可在浏览器本地转为 GIF，静态 WebP 可转为 PNG。可选择授权文件夹或在设置中下载 ZIP。

使用桌面 Chrome 和 Tampermonkey。安装后刷新抖音，点悬浮球打开面板。图片读取使用页面资源地址，转换在本地进行。保存到目录需要 Chrome 授权。

## English

Douyin Emoji Saver 5.1.0 previews and saves stickers already displayed in Douyin comments and direct messages. It supports animated and static filters, deduplication, and individual or multi-item saving. The browser converts animated WebP and APNG to GIF and static WebP to PNG. Choose an authorized folder or export a ZIP from Settings.

Use desktop Chrome with Tampermonkey. Reload Douyin after installation and click the floating button. Images are read from the page's resource URLs, and conversion runs locally. Directory saving requires Chrome permission. The interface is in Simplified Chinese.
