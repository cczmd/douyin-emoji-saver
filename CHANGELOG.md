# 更新日志 / Changelog

## 5.1.0

- 界面采用连续曲率圆角，调整玻璃高光和阴影，保留正圆悬浮球和胶囊形操作按钮。
- 公开发行包装补充了中英文元数据和版权声明，换用 gifenc 1.0.3 的可读构建，并移除启动诊断日志。

- Adds continuous corners to the existing panel, grid, controls, and preview while retaining the circular launcher and pill-shaped actions.
- Public packaging adds bilingual listing metadata and copyright notices, uses the readable build of gifenc 1.0.3, and removes the startup diagnostic log.

## 5.0.0

- 增加可拖动悬浮球、表情筛选、多选保存、跨格式去重、浏览器内转换和专用目录保存。
- Introduces the draggable launcher, sticker filters, multi-select saving, cross-format deduplication, local conversion, and folder-based saving.
